# 1D 베이즈 필터 — 복도 시뮬레이션

책 본문 [8.6절](../../../manuscript/08-확률로보틱스기초/08-확률로보틱스기초.md#86-🤖-함께-해보기--1d-필터-시뮬레이션-체험)과
짝을 이루는 실습입니다. rclpy 없이 `python3 bayes_filter_1d.py`로 바로 실행할 수 있습니다 —
차량 조작이 없는 소프트웨어 체험이므로 시뮬레이터·실차 어느 것도 필요 없습니다.

1차원 복도를 30칸(칸당 0.5m, 총 15m)으로 나누고, 그중 4칸(3, 8, 15, 22)에 문을 배치합니다.
로봇은 매 스텝 "한 칸 전진" 명령을 받지만 실제 이동량은 잡음이 섞여 있고(예측,
`predict`), "지금 문 앞인가?"를 묻는 잡음 섞인 이진 센서 관측을 받습니다(보정, `correct`).
믿음(각 칸이 로봇의 실제 위치일 확률)이 예측 단계에서 퍼지고 보정 단계에서 좁아지는 과정을
막대그래프로 확인합니다 — 8.3절의 예측-보정 사이클, 8.4절의 이산 수식을 그대로 코드로 옮긴
것입니다.

## 실행

```bash
python3 bayes_filter_1d.py
```

터미널에 매 스텝의 실제 위치·관측·최고 확신 칸을 출력하고, 마지막에 다섯 프레임(스텝 0·2·7·10·14)의
믿음 막대그래프를 나란히 그린 `bayes_filter_1d_strip.png`를 저장합니다(본문 그림 8-11의 원본).
기본 시드(`SEED = 61`)는 "첫 문 감지는 모호하게 여러 문 중 하나로 흩어지지만, 두 번째 문에서
완전히 좁혀져 그 뒤로는 예측만으로도 위치를 잘 따라가다가 세 번째 문에서 다시 확인된다"는 흐름을
보여주도록 고른 값입니다 — 시드를 바꾸면(`SEED` 값 수정) 매번 다른 궤적을 볼 수 있습니다.

## 파라미터 (스크립트 상단 상수)

| 이름 | 기본값 | 의미 |
|---|---|---|
| `NUM_CELLS` | `30` | 복도를 나누는 칸 수 |
| `DOOR_CELLS` | `[3, 8, 15, 22]` | 문이 있는 칸 인덱스 |
| `P_HIT` | `0.8` | 문 앞에서 센서가 "문"이라고 옳게 읽을 확률 |
| `P_FALSE_ALARM` | `0.1` | 문이 아닌 곳에서 "문"이라고 잘못 읽을 확률(오탐) |
| `MOTION_PROFILE` | `[0.1, 0.8, 0.1]` | 명령한 1칸 이동 대비 실제 이동량(0/1/2칸)의 확률 |
| `NUM_STEPS` | `14` | 시뮬레이션 스텝 수 |
| `SEED` | `61` | 난수 시드(재현성) |

## 함수 대응표 (8.4절 수식과 1:1)

| 코드 | 8.4절 수식 |
|---|---|
| `predict()` | 예측 단계 — 이전 믿음과 동작 모델(`motion_profile`)의 합 |
| `likelihood()` | 우도 — 관측이 각 칸에서 나올 법한 정도 |
| `correct()` | 보정 단계 — 우도를 곱하고 정규화 |
